Setup first

先建立自己的连接，再开始形成记忆。

公开版本不会复用维护者的 WPS、飞书或模型环境。安装者需要创建自己的企业应用、完成权限审批与 OAuth，并配置自己的大模型服务。

公开预览无需密钥即可运行，只展示产品结构。
WPS 连接需要安装者自己的 App ID、App Key、权限与 OAuth。
模型服务需要安装者自己的 API 地址、模型和 API Key。

安装后的五个确认

创建企业自建应用每个企业使用自己的 WPS 应用。
用户配置
申请并发布权限区分用户授权、应用授权与 delegated MCP。
管理员审批
完成用户 OAuth新增权限发布后，用户需要重新授权。
用户操作
选择大模型服务填写自己的兼容 API 地址、模型和 Key。
用户配置
运行本地预检不显示密钥，只报告缺项和下一步。
npm run preflight
Source discovery

用少量种子，让来源在用户裁决下逐步生长。

系统先提出候选，不把活跃、提及或相似内容直接当作重要事实；用户以确认、排除和暂停控制监控范围。

01

种子来源

由用户确认的少量来源与关系线索。

02

候选发现

基于行为、对象与跨来源证据提出候选。

03

用户裁决

确认、排除当前冷启动、暂停或恢复。

04

持续监控

只在已确认边界内增量读取与复核。
