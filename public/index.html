第三大脑 · 本地试用

先验证它能不能从你选择的 WPS 群聊里找到值得关注的工作信号。数据加密保存在当前电脑，只有你点击分析时才发送给你自己的 DeepSeek API。

Local-first Alpha

1. 连接状态

每位同事使用自己的 WPS 应用、OAuth 和 API Key，不共享任何人的凭证或办公数据。

2. 选择时间

首轮建议只选 1–3 个你最熟悉的群，先判断信息是否找对。

3. 选择群聊并导入

完成授权后读取会话清单。

4. 生成业务化候选

系统只提出候选，不把活跃、@ 或高频自动当作重要。你需要判断“重要、相关但非重点、噪声、不确定”。

首版只读：不会向 WPS 发送消息，不会把数据上传到维护者服务器，也不会自动扩大监控范围。
