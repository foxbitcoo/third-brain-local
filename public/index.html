报告问题 · 本地草稿

草稿、扫描、完整预览和确认回执只保存在本机。当前版本不执行 GitHub 写入；真实提交状态为 NOT_RUN。

默认零外部写入：不会向 WPS 发送消息，不会上传办公数据，也不会自动创建 GitHub Issue。真实 WPS、模型和 GitHub 能力须由每位安装者自行验证。
