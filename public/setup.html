🧠第三大脑 · Local-first Alpha
首次设置约 10 分钟
开始前，先把钥匙放在自己手里

先准备三样东西

第三大脑不会使用维护者的账号，也不会把你的办公信息送到维护者服务器。你需要创建自己的 WPS 应用、申请两项读取权限，并配置自己选择的大模型服务。

💡 这不是“技术人员专用配置”。按下面四步完成即可；每一步都写清了去哪里拿、复制什么、完成后如何判断。
01WPS 企业自建应用

提供 App ID 和 App Key，用于发起你自己的用户授权。

02两项 WPS 用户权限

在开放平台选择 user，不要选择 app。

03大模型配置

服务商、API 地址、模型名称和你自己的 API Key。

照着完成这四步

不需要 WPS_SID
1

创建 WPS 企业自建应用

打开 WPS 开放平台，进入开发者后台，新建“企业自建应用”。在应用信息页面复制 App ID 和 App Key。

打开 WPS 开放平台 ↗
2

申请并发布两项用户权限

在“权限管理”里分别搜索 kso.user_base.read 和 kso.mcp_message.readwrite。两项都选择权限类型 user，不要选择 app。不要在搜索框输入 delegated: 前缀；它是代码里的委托标记，不是开放平台可搜索的 scope。创建应用版本并等待审批发布后，再让试用者完成 OAuth。当前代码只读取会话与历史消息，不实现发送。

3

填写用户授权回调

在应用安全配置中，把回调地址完整填写为：

http://127.0.0.1:4310/oauth/wps/callback

4

准备自己的大模型 API

选择你已有的模型服务，准备 API 地址、模型名称（火山方舟可填写 Endpoint ID）和 API Key。支持标准 OpenAI-compatible Chat Completions 接口，不限定 DeepSeek；也可以使用豆包／火山方舟、OpenAI 或其他兼容服务。

隐私确认：每位试用者都应使用自己的 WPS 应用、OAuth 和模型 Key。不要把同事的凭证填在这里，也不要提交、截图或发送 .env.local。

配置保存后，在终端按 Control + C 停止服务，再运行 npm start。随后会进入 WPS 授权与群聊选择页面。
