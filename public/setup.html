🧠第三大脑 · Local-first Alpha
首次设置约 10 分钟
开始前，先把钥匙放在自己手里

先准备三样东西

第三大脑不会使用维护者的账号，也不会把你的办公信息送到维护者服务器。你需要创建自己的 WPS 应用、申请两项读取权限，并使用自己的 DeepSeek API Key。

💡 这不是“技术人员专用配置”。按下面四步完成即可；每一步都写清了去哪里拿、复制什么、完成后如何判断。
01WPS 企业自建应用

提供 App ID 和 App Key，用于发起你自己的用户授权。

02两项 WPS 权限

当前用户基础信息，以及用户委托的会话消息读取能力。

03DeepSeek API Key

只有你点击“分析”时才调用；费用由你自己的账号承担。

照着完成这四步

不需要 WPS_SID
1

创建 WPS 企业自建应用

打开 WPS 开放平台，进入开发者后台，新建“企业自建应用”。在应用信息页面复制 App ID 和 App Key。

打开 WPS 开放平台 ↗
2

申请并发布两项权限

在“权限管理”中申请 kso.user_base.read 和 delegated:kso.mcp_message.readwrite，创建应用版本并等待审批发布。当前代码只读取会话与历史消息，不实现发送。

3

填写用户授权回调

在应用安全配置中，把回调地址完整填写为：

http://127.0.0.1:4310/oauth/wps/callback

4

创建自己的 DeepSeek API Key

进入 DeepSeek 开放平台的 API Keys 页面创建 Key。模型固定为 deepseek-v4-pro，当前不接受第三方转发地址。

打开 DeepSeek API Keys ↗

都拿到了？保存在这台电脑

三个值只会写入本机权限为 600 的 .env.local，页面不会再把密钥读出来。

隐私确认：每位试用者都应使用自己的 WPS 应用、OAuth 和模型 Key。不要把同事的凭证填在这里，也不要提交、截图或发送 .env.local。

配置保存后，在终端按 Control + C 停止服务，再运行 npm start。随后会进入 WPS 授权与群聊选择页面。
