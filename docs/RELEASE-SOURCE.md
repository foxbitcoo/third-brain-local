# 公开版同步来源

本候选分支基于公开仓库 commit `16289846aa42c23a95e6429d7b4939eeae7be5cb` 建立，用于同步经第一用户确认的 Product Spec v1.5 公开边界。

本轮只包含：

- 公开版是可独立安装的 Local-first 产品版，而不是只能演示的 Demo；
- 个人版到公开版的单向同步与隐私扫描门禁；
- 私有仓库同样禁止存档 API Key、OAuth 凭证和运行时数据；
- 公开 Alpha 暂未提供 Report to Issue；后续独立 Ticket 才能重新定义和验收该能力；
- `AGPL-3.0` 许可证正文与包元数据；
- 对应的发布门禁测试。

本轮增量还包含公开安全的合成工作台：固定 7 个候选与精确 7/7 合成谱系门禁、三字段冲突确认，以及候选层不自动改写状态。

本轮包含公开安全的前端工作台与首次设置导览改动，不包含个人版的真实数据、人员、来源、裁决、内部链接、凭证或竞品研究材料。用户已于 2026-08-19 确认公开版继续同步；本分支仍须通过当前文件、完整 Git 历史、私人 denylist 和干净安装门禁，才可合并到公开仓库主分支。
