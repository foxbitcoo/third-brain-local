# 公开版同步来源

本候选分支基于公开仓库 commit `faf666306c0ef19303f3d8f23d02607bfbe7ae8b` 建立，用于同步经第一用户确认的 Product Spec v1.5 公开边界。

本轮只包含：

- 公开版是可独立安装的 Local-first 产品版，而不是只能演示的 Demo；
- 个人版到公开版的单向同步与隐私扫描门禁；
- 私有仓库同样禁止存档 API Key、OAuth 凭证和运行时数据；
- 个人版和公开版都采用本地生成、隐私扫描、完整预览、用户确认后的 Report to Issue 边界；公开版只提交到公开 Issue 池，当前 Alpha 尚未实现自动提交；
- `AGPL-3.0` 许可证正文与包元数据；
- 对应的发布门禁测试。

本轮不包含前端页面改动，不包含个人版的真实数据、人员、来源、裁决、内部链接、凭证或竞品研究材料。用户已于 2026-08-19 确认公开版继续同步；本分支仍须通过当前文件、完整 Git 历史、私人 denylist 和干净安装门禁，才可合并到公开仓库主分支。
