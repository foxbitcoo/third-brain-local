# 本地 Alpha 限制

## 已包含代码路径

- 本地安装、配置预检与回环服务；
- WPS OAuth 授权链接和 code 换 token；
- 当前用户会话列表与指定群聊消息读取；
- 最近 1–30 天、最多 10 个群的手动导入；
- 私聊默认隐藏并由服务端拒绝导入；
- 会话与消息分页完整性状态；达到 1,000 个会话或单群 2,000 条消息时明确标记截断；
- 本地加密存储；
- 安装者显式触发的 DeepSeek V4 Pro 中文候选分析；
- 每个候选最多 3 条可回查的群名、时间、短片段和消息 ID，以及四类用户裁决；
- 发布泄密扫描与干净目录安装验证。

## 发布者环境尚未真实验证

- 其他企业的 WPS 应用审批与 OAuth；
- 不同租户的会话消息分页完整性；
- Token 过期后的自动刷新；
- 图片、文件、转发、会议、文档与日历；
- DeepSeek 的真实费用、限流和结果质量。

这些能力必须由首批 2–3 名试用者逐项反馈，不能把代码存在写成真实通过。

## 暂不实现

- 自动发现和扩大监控来源；
- 后台定时任务；
- WPS 机器人发送或卡片交互；
- WPS 工作台内嵌；
- 公网服务、多用户数据库和集中式凭证托管；
- 完整 L0/L1/L2 长期记忆。
