# 隐私与隔离

## 公开仓库不包含

- 维护者或测试用户的真实消息、文档、会议、人员关系、项目、群名和裁决；
- App Key、Access Token、Refresh Token、OAuth code、Cookie、WPS_SID、模型 Key 和请求日志；
- 私人飞书/WPS 文档、截图、附件、本机绝对路径和数据导出；
- 围绕人物、项目或群聊组织的叙事型合成数据集。

测试只使用无业务叙事的最小不透明值；静态 Demo 只说明页面结构。

## 每位安装者的本地边界

- `.env.local` 保存该安装者自己的 App Key 和模型 Key，并被 Git 忽略；
- `.runtime/` 保存随机本地加密密钥、WPS Token、导入消息和分析结果，并被 Git 忽略；
- 目录和文件权限限制为当前系统用户；
- 本地密钥和密文位于同一账户下，主要防止误上传与磁盘明文泄漏，不抵御已控制本机账户的攻击者；
- 卸载时删除 `.env.local` 和 `.runtime/` 即可删除本地配置与数据。

## 外部数据流

- WPS OAuth 和消息读取只发往 WPS 官方域名；
- 模型分析只发往 DeepSeek 官方域名；
- 没有维护者遥测、分析 SDK 或远程后端；
- 不点击分析，就不会把导入消息发送给模型。

## 发布门禁

候选包运行通用泄漏扫描；维护者再用私人 denylist 扫描；最后从干净目录安装和启动。任一门禁失败都不得发布。
